# Changelog

All notable public changes are recorded here.

## 1.0.0 - 2026-08-18

- Initial open-source release under AGPLv3.
- AU, VST3, and Standalone macOS targets.
- Eight automatable parameters with host state recall.
- Eleven factory presets with in-panel and host selection.
- Resizable hardware-inspired editor with animated meters and status controls.
- DSP, UI render, repository, and plug-in host smoke tests.
- No account, activation, telemetry, analytics, or network access.
