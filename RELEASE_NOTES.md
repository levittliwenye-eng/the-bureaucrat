# THE BUREAUCRAT 1.0.0

Initial open-source release from 真理音频 / Pravda Audio, a Disconnec audio
imprint.

## Included

- macOS AU and VST3 source targets for Apple Silicon and 64-bit Intel
- Standalone development target
- Resizable 960 x 420 to 1920 x 840 interface
- Eight automatable parameters with host state recall
- Eleven host-visible factory presets and an in-panel preset selector
- Saturation, timing disruption, phase interference, low-pass filtering,
  overload band restriction, long feedback delay, and loyalty restriction modes
- DSP, UI render, open-source repository, and VST3 host smoke tests
