# Security Policy

## Supported Version

Security fixes are currently made against the latest source on the default
branch and the most recent tagged release.

## Reporting A Vulnerability

Do not publish a suspected security vulnerability in a public issue. Contact the
project owner privately through the security-reporting channel listed on the
repository host. Include the affected version, reproduction steps, expected
impact, and any suggested mitigation.

The project has no network, activation, update, or telemetry subsystem. Relevant
reports are most likely to concern malformed host state, plug-in loading,
third-party dependencies, packaging, or local file handling.

Please allow reasonable time for confirmation and a coordinated fix before
public disclosure.
